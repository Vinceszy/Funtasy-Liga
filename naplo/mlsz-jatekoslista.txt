# 3. KOR - a fordulonkenti pont utolso eselye (pontbontas-vegpont).
# Elozmeny: a torzs (competitions/3/players) megvan, de fordulora nem
# szurheto (400). Itt a /game-player-stats vegpontot meritjuk ki.
# Merott jatekos-azonositok: [1237, 1303]

## a) EGY jatekos, fordulo-szuro NELKUL - megjon-e az egesz szezon?
=== csak jatekos-szuro                                   -> HTTP 200 | sorok=50 total=109 per_page=50 last_page=3
    elso sor (RÖVIDÍTVE, de MINDEN mezo):
{
 "value": 1,
 "points": 3,
 "round_id": 77,
 "competition_stat_config": {
  "id": 59,
  "name": "Győzelem"
 }
}
    -> 50 sorban 3 kulonbozo fordulo: [77, 79, 81]
=== csak jatekos-szuro + per_page=100                    -> HTTP 200 | sorok=50 total=109 per_page=50 last_page=3
    -> 50 sorban 3 kulonbozo fordulo: [77, 79, 81]

## referencia: ugyanaz a jatekos, EGY fordulora (a mai mukodo hivas)
=== jatekos + 5. fordulo                                 -> HTTP 200 | sorok=22 total=22 per_page=50 last_page=1
    -> 22 sorban 1 kulonbozo fordulo: [85]

## c) TOMEGES hivas (csak fordulora szurve) - a nyers sor MINDEN mezoje.
#    Ha van benne barmilyen jatekos-azonosito, az egesz mult potolhato
#    par keressel. Az 1. kor szerint nincs - ezt ellenorizzuk ujra.
=== csak fordulo-szuro + per_page=500                    -> HTTP 200 | sorok=50 total=3322 per_page=50 last_page=67
    elso sor (RÖVIDÍTVE, de MINDEN mezo):
{
 "value": 1,
 "points": 3,
 "round_id": 85
}
    az elso 50 sor OSSZES mezoneve: ['points', 'round_id', 'value']
    azonositonak tuno mezok: ['round_id']
      round_id                         -> 1 kulonbozo ertek az elso 50 sorban, pl. ['85']

## d) a torzsvegpont: fordulonkenti include, es elfér-e egy lapon?
