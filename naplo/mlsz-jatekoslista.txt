# 7. KOR: van-e teljes menetrend (jovobeli meccsek) az MLSZ-nel?
# A profil elore is felsorolja a fordulokat - ott az ELLENFELNEK latszania
# kell, csak a pont ures. Ma a meccsek.json csak a megjart fordulokat ismeri.
# Probafordulo: 8. (round_id=91)

## 1) onallo meccs-vegpontok
=== games?filter[round_id]                 -> HTTP 404
=== competitions/N/games                   -> HTTP 404
=== competitions/N/games (szuro nelkul)    -> HTTP 404
=== matches?filter[round_id]               -> HTTP 404
=== fixtures?filter[round_id]              -> HTTP 404
=== competitions/N/rounds                  -> HTTP 404
=== competitions/N/rounds + games          -> HTTP 404

## 2) tartalek: a keret-vegpont meccslistaja egy JOVOBELI fordulora
=== keret-vegpont (user_id nelkul) -> HTTP 200
    (nincs lista - a vegpont user_id nelkul valoszinuleg nem ad adatot)

### Ha egyik vegpont sem adja a jovot, a gyujtonek fordulonkent kell
### lekernie a meccslistat - egyszer, mert a menetrend nem valtozik.
