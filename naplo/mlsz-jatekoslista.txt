# 10. KOR: van-e teljes menetrend (jovobeli meccsek) az MLSZ-nel?
# A profil elore is felsorolja a fordulokat - ott az ELLENFELNEK latszania
# kell, csak a pont ures. Ma a meccsek.json csak a megjart fordulokat ismeri.
# Probafordulo: 8. (round_id=91)

## 1) onallo meccs-vegpontok
=== games?filter[round_id]                 -> HTTP 404
=== competitions/N/games                   -> HTTP 404
=== competitions/N/games (szuro nelkul)    -> HTTP 404
=== matches?filter[round_id]               -> HTTP 404
=== fixtures?filter[round_id]              -> HTTP 404
=== competitions/N/rounds                  -> HTTP 404
=== competitions/N/rounds + games          -> HTTP 404

## 2) A jatekos-adatlap vegpontja (a felulet ezt mutatja)
=== players/{id}                     -> HTTP 200 | felso kulcsok: ['birth_date', 'countries', 'extended_summary_statistics', 'fantasy_summary_statistics', 'first_name', 'id', 'injury_status', 'is_u21', 'last_name', 'position', 'profile_picture', 'rounds', 'team']
=== players/{id} + team.games        -> HTTP 200 | felso kulcsok: ['birth_date', 'countries', 'extended_summary_statistics', 'fantasy_summary_statistics', 'first_name', 'id', 'injury_status', 'is_u21', 'last_name', 'position', 'profile_picture', 'rounds', 'team']
=== players/{id} + games             -> HTTP 200 | felso kulcsok: ['birth_date', 'countries', 'extended_summary_statistics', 'fantasy_summary_statistics', 'first_name', 'id', 'injury_status', 'is_u21', 'last_name', 'position', 'profile_picture', 'rounds', 'team']
=== players/{id} + next_games        -> HTTP 200 | felso kulcsok: ['birth_date', 'countries', 'extended_summary_statistics', 'fantasy_summary_statistics', 'first_name', 'id', 'injury_status', 'is_u21', 'last_name', 'position', 'profile_picture', 'rounds', 'team']
=== players/{id} + upcoming_games    -> HTTP 200 | felso kulcsok: ['birth_date', 'countries', 'extended_summary_statistics', 'fantasy_summary_statistics', 'first_name', 'id', 'injury_status', 'is_u21', 'last_name', 'position', 'profile_picture', 'rounds', 'team']
=== players/{id} + fixtures          -> HTTP 200 | felso kulcsok: ['birth_date', 'countries', 'extended_summary_statistics', 'fantasy_summary_statistics', 'first_name', 'id', 'injury_status', 'is_u21', 'last_name', 'position', 'profile_picture', 'rounds', 'team']
=== players/{id}/games               -> HTTP 404 (nem JSON objektum)
=== players/{id}/next-games          -> HTTP 404 (nem JSON objektum)
